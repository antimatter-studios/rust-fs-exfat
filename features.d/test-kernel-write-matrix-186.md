The read-only Linux kernel's tree, bytes, ReadOnly flags and modified, accessed and created times then equal the strict reader's. After the equivalent kinds made by the kernel on a read-write mount (the label by exfatprogs' `exfatlabel`), the strict reader sees the kernel's listing and created times, the unchanged kernel sentinel and each kind's intended result. Scoped platform differences: Linux 6.1 shows truncate-grown files only to ValidDataLength (#207); a case-only rename(2) is a no-op on Linux; the kernel shows no label, Hidden, System or Archive bit.
